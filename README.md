# ♕ N-Queen Visualizer (Web-Based)

This is a visual and interactive implementation of the classic **N-Queens Problem** using **HTML, CSS, and JavaScript**. It allows users to visualize how queens are placed on a chessboard such that no two queens attack each other.

---

## 🎯 Features

- ✅ Choose custom grid size (N × N) – supports N from 4 to 20.
- 🕒 Adjustable animation speed with a slider.
- ♟️ Color-coded visualization of queen placement and attacks.
- 🔁 Clear board and re-run at any time.
- 🌐 Pure frontend (HTML + JS) – No backend or installations required.
- 🚀 Ready to deploy via GitHub Pages or run with VS Code + Live Server.
